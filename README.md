## Soluções na prática

| Solução | Aplicação |
| :--- | :--- |
| **Assistente de escrita profissional** | Revisão de textos, contextos de comunicação, documentos Word e reescrita local opcional. |
| **Ferramentas para planilhas** | Consolidação de CSV, correspondência de colunas, prévia e conferência de duplicatas. |
| **Painel de ferramentas** | Acesso central aos recursos, busca, favoritos e consulta dos serviços locais. |
| **Automações de apoio** | Rotinas locais para simplificar tarefas e acompanhar o funcionamento do computador. |
