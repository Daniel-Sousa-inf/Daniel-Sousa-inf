# Daniel-Sousa-inf

**Melhorias práticas para textos, planilhas e processos de trabalho.**

Crio ferramentas para facilitar tarefas do dia a dia: escrever com mais clareza, organizar informações e reduzir trabalho repetitivo.

## Meu foco

| Área | O que procuro melhorar |
| --- | --- |
| Escrita profissional | Revisão de textos, e-mails, contextos e tons de linguagem. |
| Documentos | Revisão de conteúdo e organização de arquivos Word. |
| Planilhas | Consolidação de dados, conferência de colunas e identificação de duplicatas. |
| Automações | Rotinas locais que tornam o trabalho mais simples e consistente. |

Meus projetos combinam **JavaScript, PowerShell, HTML e CSS**, com extensões para Chrome, revisão por **LanguageTool** e reescrita opcional com **Ollama**.

Valorizo ferramentas fáceis de usar, testes com exemplos e conferência dos resultados antes de aplicar mudanças.
